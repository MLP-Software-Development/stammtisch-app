# Stammtisch (working title)

An app for small groups that meet regularly — a monthly Stammtisch, a bowling club, a circle of friends — to plan
events, answer yes or no in one tap, get reminded in time, and keep the shared cash box, photos and documents in one
place instead of scattered across a chat.

**Status: concept phase.** Nothing is built yet. The product is being charted as a
[wayfinder map](https://github.com/MLP-Software-Development/stammtisch-app/issues?q=label%3Awayfinder%3Amap) on this repo's
issues: every open question is an issue, every decision is recorded on the issue that settled it.

Planned path: concept (this map) → Figma → web app → iOS and Android apps.

## Principles

- Simple first. Smart defaults, few options, nothing a casual member has to learn.
- Built for one real group, modelled for any group.
- The UI is German. Code, docs and issues are English.
