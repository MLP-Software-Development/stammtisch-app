# Stammtisch app — agent rules

Read [README.md](README.md) for what this is. This repo is public: everything committed or written to an issue is
visible to anyone.

## Language

- **UI copy is German.** No i18n layer yet; do not add one.
- **Code, docs, issues, commit messages are English.**
- **Domain terms are English**, as defined in [GLOSSARY.md](GLOSSARY.md). No German words in code or domain language.

## Privacy in a public tracker

Never name real people, the real group, its members, places or bank details in issues, commits or docs. Examples use
invented names.

## Way of working

The product is charted as a wayfinder map on GitHub issues (label `wayfinder:map`). A feature goes idea → concept →
Figma → build; a brief that skips a step goes back as a question.

## Agent skills

### Issue tracker

GitHub issues on this repo, wayfinder map with sub-issues and native blocking. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: `GLOSSARY.md` at the root, ADRs in `docs/adr/`. See `docs/agents/domain.md`.
